# Уроци по перкусии

Игра за ученици: уроци по ред, всеки казва какво се учи, а нотите се свирят такт по такт.
Засега: малък барабан (12 урока — от четвъртини до групи с шестнайсетини). Нов инструмент се добавя в `app/lessons.json`.

## Пускане

```
pip install -r requirements.txt
python main.py
```

## Управление

- `Интервал` — свири / спри
- `←` `→` — предишен / следващ такт
- Всички уроци са отворени — програмата е за учители, които обясняват на децата.
- Два режима: „Автоматично“ — минава такт по такт сам, докато свърши урокът.
  „Ръчно — аз сменям“ — повтаря текущия такт, а учителят превключва
  със „Следващ такт“ / „Предишен такт“, когато реши.
- Изсвирен от първия до последния такт в автоматичен режим, урокът получава отметка ✓.

## Как се добавя урок

Уроците са в `app/lessons.json`. Всеки такт е един ред текст, ударите са разделени с интервал:

```
"q:hh+bd 8:hh 8:hh+sd q:r q:sd:R"
```

- първата част е дължината: `w` цяла, `h` половина, `q` четвъртина, `8` осмина, `16` шестнайсетина; `d` накрая = с точка (`qd`)
- втората част е ударът (от `voices` на инструмента); `+` = едновременно; `r` = пауза
- третата част (по желание) е надпис под нотата, напр. `R` / `L` за ръка

Ако тактът не е с правилна дължина, в конзолата излиза предупреждение.

Нотите се рисуват с [VexFlow](https://github.com/0xfe/vexflow) 4.2.5 (`app/vendor`, MIT).
